# 🎓 Star Classes: Course Institute Website

A front-end website for **Star Classes**, a computer-course institute. Visitors can browse courses, meet the teachers and get in touch.

Built with **HTML and CSS** as an Aptech e-project.

🔗 **Live demo:** https://front-end-website-eosin.vercel.app

> 📸 _Screenshots coming soon_

---

## ✨ Features

- 🏠 **Home page** with a hero slider, institute features (scholarships, online courses, global certification) and popular courses
- 📚 **Course pages**: Advanced Excel, AI for Everyone, Amazon Virtual Assistant, ChatGPT for Developers, Office Automation, Social Media Marketing
- 👨‍🏫 **Certified teachers** section
- ℹ️ **About**, 📬 **Contact** and 🔐 **Login** pages

## 🛠️ Tech Stack

HTML5 · CSS3

## 🚀 Run it locally

No build step. Clone the repo and open `E-project Star Classes/index.html` in your browser.
